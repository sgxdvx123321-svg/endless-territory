## 一 · 基礎期 v2 – v5（地圖與結構）

| 版本 | 關鍵改動 |
|---|---|
| **v2** | 基準版。區塊制世界（8×6，每塊 28×19）、吃光已開放區塊才開新塊、窒息死亡、可縮放視角 |
| **v3** | 加入**地區 + 主城**：每塊 4–6 個連通地區，主城在陸地最密的格；站在城內 5 秒攻下，地區被吃光 1.2 秒自動歸降 |
| **v4** | 世界改成**一整塊大陸**，開圖改成同心圈擴張；`sealSeam()` 保證接縫夠寬 |
| **v5** | 修掉 v4 的致命問題（矩形揭露造成孤島 → 卡死）。區塊 24×16、世界 10×8（240×128）、每局隨機種子、大陸遮罩、洪水填充保證可達性 |

**為什麼要改**：v2 的 AI 會站著不動；v3 加了地區節點讓攻略有目標；v4 想做整塊大陸但邊界還是矩形；v5 才真正做到「一塊大陸 + 不會卡死的開圖」。

**這一段的核心**：讓世界有質感（地質/人口）、讓敵人會反擊，然後把「太強」拆成可調的旋鈕。

| **v15** | **不再被推走**（改成移動阻擋）、**BFS 尋路**、據點經濟（守軍池/上限/`N` 抽調/自動補滿/解散/一城一軍）、城池命名（300 個古風城名）、面板收折、**自動存檔** |

## 設計演進的四條主線

### 1. 地圖：從「開箱子」到「一張大陸」
```
v2 8×6 區塊揭露 → v4 一整塊大陸（同心圈）→ v5 大陸遮罩
→ v14 第二片大陸（已移除）→ v21 63 區塊 + 完整大陸模式
→ v21.1/21.2 區塊優先的國界生成
```

### 2. 兵團：從英雄到陣法
```
v6 英雄本體 → v7 兵團即棋子 → v14 軟推擠 → v15 阻擋+尋路
→ v18 目標分配 → v24 兵種數值 → v26 守軍數字化
→ v27–v31 統合兵團（陣法、穿透、傳送歸隊）
→ v34/v37 編隊操作（拖曳 → 右鍵）、v36 攻擊優先
```

### 3. 外交：從無到全矩陣
```
v14 玩家單向（和平/宣戰）→ v17 敵國一律結盟
→ v21b 三態矩陣（和平/戰爭/同盟）+ AI 自動外交
→ v23 開局全和平 + 一鍵切換 → v38 區塊模式也開放、消亡勢力保留戰史
```

### 4. 難度：從固定到玩家驅動
```
v7.2 隨區塊成長 → v8 守城優勢（v8.1 回調）→ v9 第 11 塊才生效
→ v25 看玩家兵力/城池換算 → v32 三軍團制 + 分兵 → v33 守軍定期轉野戰軍
→ v34 敵軍攻擊性上調 → v36 被圍城斷絕補兵
```

## 已被移除的機制（避免誤會）

| 機制 | 出現 | 移除 | 原因 |
|---|---|---|---|
| 英雄本體 | v1–v6 | v7 | 改成兵團即棋子 |
| 物理軟推擠 | v14 | v15 | 會被推到遠處、沿途佔地、卡水 |
| 自動歸降 | v3 | v32 | 改成只加速攻城（避免整區被繞過就白白送城） |
| 第二大陸 / 大一統帝國 | v14 | v21 | 改成單一大陸 + 多政權 |
| 一國一統合兵團 | v27 | v28 | 改成每支兵團自選 1–4 隊 |
| 敵國「幾支兵團 × 兵力加成」 | v7–v31 | v32 | 合併成固定 3 支、總兵力均攤 |
| 左鍵拖曳編隊 | v34 | v37 | 改成右鍵，左鍵留給點選／改名 |
| 外交解鎖閘 | v14 | v38 | 區塊模式也直接開放外交 |
